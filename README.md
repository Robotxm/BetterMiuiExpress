# BetterMiuiExpress

BetterMiuiExpress 用于禁止 MIUI/HyperOS 的快递小部件跳转到淘宝、菜鸟等第三方应用，同时使用一个自定义的界面来显示快递详情。

同时对于新版本智能助理中，京东快递会跳转京东 App 的场景进行了屏蔽，恢复原有跳转行为。

**如果顺丰快递的收件人信息使用了隐私手机号，无法保证一定能查询到快递详情。**

## 系统要求

- 基于 Android 8.0 或更高版本的 MIUI/HyperOS
- 装有 MIUI/HyperOS 的智能助理 App
- **仅支持 LSPosed 框架**

## 用法

- 确保已经安装 LSPosed
- 下载或自行编译模块。**如果从 1.6.0 或更低的版本升级，建议卸载旧版本后再安装**
- 在 LSPosed 管理器中启用模块。默认已经将“智能助理”作为作用域推荐应用勾选。如果没有自动勾选，请尝试手动勾选，可能需要在右上角的菜单中取消勾选“系统应用”
- **首次使用前，或者从 1.7.4 或更低的版本升级后**，请先进入模块主界面，等待提示“初始化完成”
- 通过 LSPosed 管理器或系统设置强制停止“智能助理”运行
- 现在点击负一屏或桌面上的快递小部件，将不会再跳转到第三方应用，同时可以在卡片中看到最新的快递动态

## 需要取件码的快递

如果有需要取件码的快递，点击快递详情页面右上角的菜单，选择“转到第三方应用”即可。

## 模块热重载

- 在支持 libxposed API 102 热重载的 LSPosed 框架中，更新模块 APK 后会自动尝试加载新代码，无需重启智能助理。
- **首次升级到支持热重载的版本后，仍需强制停止并重新打开一次智能助理**，后续更新才能热重载。YukiHook 内部语义版本变化时也需要重启宿主。
- 自动重载未生效时，可从 LSPosed 管理器进入模块主界面，点击“应用模块更新”，查看各个智能助理进程的重载结果。
- 快递查询、缓存写入或宿主搜索回调尚未结束时会拒绝重载，以避免新旧代码同时修改数据。请等待任务完成后手动重试，或重启智能助理。
- 不支持热重载的框架仍可使用模块，更新后按原方式重启智能助理即可。

开发接入说明见 [YukiHook 模块热重载文档](https://highcapable.github.io/YukiHook/zh-cn/library/yukihook-core/hot-reload)。
